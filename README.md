# New Era CAD downloads

What's new: Quick measure finds the cut lines an L's scribe ends finish against; Measure tool numbers sit outside, bottom toward the points.

Older versions and their notes: [Releases](https://github.com/MAJIN32Bit/DR-STONE-downloads/releases).
